# Data

`raw/` contains the original UCI archives used by the experiment scripts. No edited feature matrices are needed. The two archives can be checked with `python scripts/verify_data.py`.

| Dataset | DOI | UCI record |
| --- | --- | --- |
| Beijing Multi-Site Air Quality (Song Chen, 2017) | 10.24432/C5RK5G | https://archive.ics.uci.edu/dataset/501/beijing+multi+site+air+quality+data |
| Gas Sensor Array Drift Dataset (Alexander Vergara, 2012) | 10.24432/C5RP6W | https://archive.ics.uci.edu/dataset/224/gas+sensor+array+drift+dataset |

Both UCI records state a CC BY 4.0 license. The MIT license in the repository root applies to repository code, not to these datasets. Cite the original UCI records when using the data.
